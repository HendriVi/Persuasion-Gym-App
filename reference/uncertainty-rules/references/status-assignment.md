# Status Assignment Decision Rules

## Epistemic decision sequence

Ask in order:

1. **Is it directly present/measured?** → `OBSERVED`.
2. **Is it a taxonomy/classification applied to anchored material?** → `ANNOTATED`.
3. **Does it follow deterministically from accepted inputs?** → `DERIVED`.
4. **Is it something a source/person says?** → `REPORTED` unless independently verified.
5. **Does evidence support a conclusion not directly observed?** → `INFERRED`.
6. **Is it an explanatory possibility proposed for testing?** → `HYPOTHESIZED`.
7. Otherwise → `UNKNOWN`.

Never pick a stronger-sounding label for stylistic reasons.

## Verification decision sequence

1. Is the proposition externally checkable? If no → `NOT_APPLICABLE`.
2. Is there an authoritative/current source capable of settling it? If not retrieved or inadequate → `UNVERIFIED`.
3. Does the source directly support the proposition within exact scope? → `VERIFIED`.
4. Does it support only a materially qualified version? → `VERIFIED_WITH_QUALIFICATION`.
5. Does direct credible evidence contradict it within matched scope? → `CONTRADICTED`.
6. Is the proposition time-sensitive and no longer current? → `OUTDATED`.
7. Do credible sources conflict or fail to settle it? → `UNRESOLVED`.

## Mechanism/causal decision sequence

1. Identify the exact relation being graded.
2. Separate effect evidence from mechanism evidence.
3. Identify evidence basis and scope.
4. Ask whether rival mechanisms were discriminated.
5. Ask whether temporal order and causal assumptions are defensible.
6. Grade `ESTABLISHED` only with convergent direct evidence and characterized limits.
7. Use `SUPPORTED` for good direct support with remaining uncertainty.
8. Use `PLAUSIBLE` for indirect, mixed, extrapolated, or underidentified support.
9. Use `SPECULATIVE` for weak/theoretical/analogy-based links.
10. Use `MIXED` for credible conflicting patterns; `UNKNOWN` when evidence is insufficient.

## Person-specific activation decision sequence

Artifact-only analysis cannot exceed `CANDIDATE`.

`EPISODE_CONSISTENT` requires episode-level information compatible with the mechanism but not sufficiently discriminating.

`SUPPORTED_IN_EPISODE` requires convergent, temporally appropriate evidence that favors the mechanism over credible alternatives.

`EXPERIMENTALLY_IDENTIFIED` requires a valid within-person/episode-relevant manipulation or equivalent identification strategy capable of isolating the mechanism to the stated scope.
