# Persuasion Systems Thinking Skill

A domain-adapted systems-thinking skill for Persuasion Gym.

## Files

- `SKILL.md` — operational skill instructions
- `references/evidence-and-causality.md` — evidence grading and causal-language rules
- `references/persuasion-system-ontology.md` — stable layers and variable vocabulary
- `assets/system-analysis-template.md` — reusable output template

## Design goal

Connect specialist findings into a dynamic, testable system model without using systems diagrams to manufacture causal certainty.

## Recommended stack position

De-Spin → Critical Thinking → Rhetorical Structure → Persuasion Mechanism → **Persuasion Systems Thinking** → Fact/Scientific verification → Training
