# Persuasion Influence Systems Analysis

Operational multi-level systems-analysis skill for Persuasion Gym.

## Role

Consumes message-level and person-level outputs and models how influence may propagate through behavior, groups, networks, platforms, institutions, and feedback over time.

## It does not own

- rhetorical annotation;
- psychological mechanism discovery;
- factual verification;
- argument validity;
- manipulation verdicts;
- hidden-intent inference;
- quantitative forecasting without a calibrated model.
