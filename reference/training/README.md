# Persuasion Training Skill

Operational adaptive-training layer for Persuasion Gym.

It sits **above** the specialist analysis stack and **on top of** the Persuasion Agentic Learning substrate.

It does not decide what is rhetorically, factually, logically, psychologically, or systemically correct. Those conclusions come from specialist modules and are frozen into validated answer keys before training begins.

The training skill owns:

- target selection;
- item presentation;
- commit-first interaction;
- confidence capture;
- criterion scoring;
- error diagnosis;
- formative feedback;
- retry/contrast/transfer selection;
- learner-model updates;
- mastery-state transitions.

Core principle:

> The AI should make the learner do more of the reasoning over time, not less.
