# Persuasion Gym Manipulation Boundary

This package defines the operational boundary between persuasion, manipulation, deception, coercion, exploitation, nudging/choice architecture, and dark-pattern-like influence for Persuasion Gym.

## Normative source

`MANIPULATION_BOUNDARY.md`

## Machine-readable policy

`assets/manipulation-policy.json`

## Compatibility

Designed to use the existing `ManipulationModule` and canonical dimension IDs in `persuasion-gym-common-schema`.

## Principle

Do not classify manipulation from rhetoric alone. Assess material impairment of informed or meaningfully voluntary choice using explicit evidence, dimension by dimension.
